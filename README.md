# All-Am Machining — website preview

A website built for **All-Am Machining** (Tracy, CA) by Anish Pattanaik, founder of FIRST Tech Challenge Team 36674 Apex Robotics.

This is a **preview**. It is hidden from search engines and shows a small "Preview" strip at the top until the business approves it.

## Editing
All of the text — hours, phone, services, FAQ — lives in `content.js`. Edit it and refresh. Lines marked `// CONFIRM` are details to double-check with the owner.

## Launching
1. Delete `preview.js` and its `<script src="preview.js">` line in `index.html`.
2. Remove `<meta name="robots" content="noindex, nofollow" />` from `index.html`.
3. Point the business's domain at this site (GitHub Pages → Settings → Pages → Custom domain).

Built with React 18 (no build step). Questions: anish.pattanaik2011@gmail.com
